# 拾知 · 本地面试资料库

个人使用的跨平台桌面应用。当前 v0.9.1 支持网站资料采集、本地 Markdown 阅读、版本与备份、DeepSeek / Ollama 问答，以及 Qwen 向量检索和精排。现已支持简历/JD、题库、文字模拟面试和针对性复习。

## 开发运行

需要 Node.js 24 或更高版本（使用内置 SQLite）以及 npm。

```bash
npm ci
npm start
```

首次运行需要下载 Electron。开发环境和正式应用使用相同的本地资料格式；测试通过独立临时目录隔离数据。

## 使用方式

1. 添加网站入口。首批适配小林 coding、JavaGuide，其他网站使用通用正文识别。
2. 点击「扫描网站」，发现同源链接；扫描完后按栏目采集，或搜索、勾选具体文章后采集。扫描数量是候选页面数，导航页可能没有可提取正文。
3. 需要登录时点击「登录网站」，手动完成验证，然后继续任务。内嵌登录能否成功由网站决定；应用不绕过付费、验证码或访问限制。
4. 在「资料库」中按网站、栏目搜索标题或正文，阅读内容、查看历史版本或打开 Markdown。
5. 点击「更新」采集所选范围：逐篇选择时仅更新最近一次选择的链接；按栏目选择时重新发现并采集栏目内容。源站 404/410 只标记文章状态，不删除本地副本。
6. 在「备份与迁移」导出 `.ikb` 文件，在另一设备选择该文件，校验后合并导入。

每个来源串行采集，请求间隔至少 1 秒。临时失败最多重试 3 次；未下载图片标记为部分完成，可以重试。应用重启后中断任务显示为暂停，需手动继续。

## 逐篇选择与采集质量

- 扫描完成后展开「逐篇选择文章」，按标题、栏目或 URL 搜索，也可筛选栏目。每页最多 50 条，支持逐篇勾选、选择本页和清空选择；勾选跨搜索和分页保留。
- 「排除路径前缀」使用逗号或换行分隔，例如 `/news/, /about`，匹配 URL 路径开头，不使用通配符。排除项不会提交；清空排除条件后仍保留原勾选。过滤条件只用于本次选择，不影响独立的「采集所选栏目」按钮。
- 「采集所选文章」会用本次链接替换该网站的逐篇更新范围；后续「更新」不再扫描扩展新链接。重新按栏目采集可切回栏目范围。网站卡片展示当前更新范围。回收站文章跳过，不会自动恢复。
- 网站来源的「单篇采集」、任务结果的「预览 / 单篇采集」、资料库的「预览 / 单篇重采」均可打开规则预览。输入同源链接，选择规则后点击「按当前规则采集此页」。此操作只采集该页，不改变网站更新范围；规则只用于该任务，除非另行保存到网站。来源已移除时需重新添加；回收站文章需先恢复。
- 任务结果可按「仅看待检查」筛选错误与质量提示。检查包括：正文少于 120 字符、疑似登录/解锁提示、空代码块、链接密集、图片地址缺失或下载失败。提示仅供人工判断，不会自动删除文章，也不会因为疑似短文而阻止入库。需要登录的页面仍暂停，待手动登录后继续。
- 预览不下载图片，无法验证图片能否成功保存。正式采集后的检查结果随文章版本保存，资料库阅读时可查看；旧版本没有检查结果，不在后台自动重采。未变化的正文复用原版本，内容变化才新增版本。

文章列表延迟筛选并分页显示；历史任务明细首次展开后才加载到界面。采集任务保存当时的提取规则，暂停或重启后继续使用该规则；更换规则应创建新任务。

## 删除与恢复

- 网站卡片提供「删除来源」，确认后移除来源及该网站的采集任务，已采集文章和历史引用保留。重新添加同源网站可恢复原来源配置；这不等于退出网站登录。
- 「资料库」可选择文章点击「删除文章」，也可勾选本页（最多 50 篇）后「删除所选」。文章移入回收站，不再参与搜索及新的知识库检索。网页更新不会自动恢复已删除文章。
- 点击资料库中的「回收站」查看原文，可逐篇或勾选本页恢复。恢复后重新进入检索；已启用的向量索引会按配置补齐。回收站搜索按标题和栏目匹配。
- 「采集任务」支持单条删除和清理已完成记录，操作前都有确认。删除不会影响已经保存的文章；进行中的请求即使稍后返回，也不再写入文章或恢复任务记录。已经发出的网络请求不一定能立即中断。

本版文章删除是可恢复删除，仍保留本地 Markdown、图片和历史版本，不释放这些文件占用的磁盘空间，也没有「清空回收站」。来源配置保留用于旧文章归属和重新添加。备份包含回收站文章与已移除来源的元信息；导入到新库保留这些状态，合并到已有库时以本机的删除/恢复状态为准，不由旧备份覆盖。问答、面试和复习记录不受文章删除影响。

## 网页提取规则

新增网站时可选择自动匹配、通用、小林 coding、JavaGuide 或代码随想录规则。已添加的网站保留原来的规则选择，可点击网站卡片上的「提取规则」修改。

1. 以代码随想录为例，在「提取规则」中选择「代码随想录」，输入具体文章链接，点击「预览提取」。
2. 切换「阅读效果」与「Markdown 源文」，检查代码、标题、表格和折叠内容。预览复用该网站登录会话，不保存文章或下载图片；仅允许当前网站地址。
3. 点击「保存到此网站」，关闭窗口，再点击来源的「更新」重新采集。已有文章保留历史版本。规则不会立即改写历史 Markdown；任务进行中不能修改规则，先暂停并等待当前请求结束。
4. 高级用户可选择「自定义规则」，编辑 JSON 中的正文/标题/链接 CSS 选择器、排除元素、发现链接的路径前缀，以及代码和折叠内容处理开关。也可导入或导出 JSON 规则，在其他网站或设备复用。

规则格式 v1 为声明式配置，不执行 JavaScript。示例：[代码随想录规则](docs/rules/programmercarl.json)。`pathPrefixes` 约束从链接发现的页面，不阻止读取网站入口进行扫描，也不取消已保存文章的更新。空数组代表不限同源路径。登录和同源限制不会被规则覆盖。

代码随想录规则清理代码行号和链接图标提示，保留语言标记、缩进和各语言代码。当前尚未提供可执行脚本插件、点击交互/强制等待网页加载、公式排版或可视化 CSS 元素选择器。

所选规则、逐篇更新范围和文章版本质量结果随备份迁移；导入已有同源网站时保留本机规则与更新范围设置，可用单独 JSON 导入明确替换。

## 配置 DeepSeek 与提问

1. 打开「模型设置」，选择「DeepSeek / 兼容接口」。基础地址为 `https://api.deepseek.com`，模型名可修改为账户支持的模型。
2. 只在应用中填写自己的 API Key，点击「保存并测试连接」。系统密钥存储不可用时拒绝保存密钥；更换地址会清除旧密钥。
3. 打开「知识库问答」，选择网站、栏目或主题关键词后提问。在线请求只发送问题和最多 8 个相关段落，总计最多 18000 字符。
4. 点击答案下的引用，查看当时的文章版本、行号及原文。勾选「允许模型补充」后，非资料内容会单独显示。
5. 本地使用时先安装 Ollama 并下载模型，在设置中保存地址和实际模型名，然后在提问处切换到 Ollama。默认地址为 `http://127.0.0.1:11434`。

问题在请求前落库；失败、超时和取消均可重试，旧记录保留。重启不会自动发送上次未完成的问题。没有候选资料且未允许补充时直接提示不足，不调用回答模型。关键词索引同步更新；向量索引在启用后由后台增量维护，界面显示进度和错误。

## 启用向量检索与精排

「模型设置」下方默认提供 `qwen3.7-text-embedding-flash`（1024 维）与 `qwen3.7-text-rerank`。勾选混合检索，填写各自完整接口地址和 Key，点击「保存并测试检索」，然后「建立 / 继续索引」。具体地址格式与协议说明见 [向量检索说明](docs/verification/vector-retrieval.md)。

线上建索引会分批发送资料片段到 Embedding 服务；精排会发送问题和候选片段到 rerank 服务。密钥独立加密保存，不导出。也可配置本机 Ollama Embedding，并关闭线上精排。首次启动索引后自动处理新资料，暂停或失败时停止请求；重建会再次调用模型。

密钥不回传界面，不进入备份。换电脑后需重新设置模型。当前 macOS 包未做发行签名，系统钥匙串可能在更新后重新请求授权。不要同时运行新旧版本操作同一个资料库。

## 管理提问记录

在「知识库问答」左侧新建分类，通过下拉框筛选记录。勾选一条或多条记录后可移动到分类或批量删除；每条记录也提供独立删除按钮。删除需要确认，会停止所选记录正在进行的生成，只删除问题与答案，不删除资料原文。

每条记录属于一个自定义分类，新问题与旧记录默认未分类。选择具体分类后可重命名或删除分类；删除分类会将其中记录移到「未分类」。分类名最多 60 字，同名分类不能重复创建。

新版备份格式为 v8，包含空分类和记录归属，支持导入 v1/v2/v3/v4/v5/v6/v7 旧备份。同名分类导入时合并，问答冲突仍保留双方。删除仅作用于本机当前资料库，不会修改既有备份；重新导入含这些记录的旧备份，会重新导入它们。v0.8.0 及更早版本不能读取新版数据库和 v8 备份，请两台设备都升级。

## 题库与模拟面试

1. 在「面试资料」粘贴简历/JD，或导入文本型 PDF、Word `.docx`；预览修正后保存。单文件不超过 10 MiB、200 页 PDF，确认文本不超过 30000 字符。不支持旧 `.doc`、扫描件 OCR 或密码保护文档。
2. 在「题库」手工录题，或选择资料文章生成候选题，勾选确认后才入库。题目保留来源及历史版本引用。
3. 在「模拟面试」选择专题或岗位模式、题库抽题或 AI 出题。岗位模式需选择简历和 JD；默认 5 题，可选 1–20 题，追问计入总量。题库不足会提示补充。
4. 练习模式逐题展示反馈；正式模式结束后展示评分和参考答案。草稿和回答本地保存，失败可手动重试；重启不会自动发送请求。
5. 报告包含逐项评分、改进建议和复习引用。技术题权重为 50/30/20，项目题为 25/30/30/15，由程序计算总分；平均分只计算已评分题。

文档提取在本机完成。使用在线模型面试会发送选定简历/JD、题目和作答上下文；AI 出题还会通过已配置的检索服务查询相关资料。原始简历文件与密钥不进入备份，确认保存的文本和场次快照会进入备份。删除原资料或题库条目不会改变历史面试。

## 针对性复习

1. 完成或提前结束面试后，在报告中点击「加入复习」。同一场次同一道题重复点击不会新增条目；未作答的题目也可加入。
2. 在侧栏「复习」按知识点、掌握状态或题目关键词筛选；每页最多显示 50 条，选中后加载回答详情。
3. 选择在线模型或 Ollama，点击「再练一次」开始单题练习。保留原题、引用和当时的简历/JD，无需重新选题；提交回答时才调用模型评分。
4. 完成后返回「复习」，对照最初回答与任意一次已评分重练的回答、评分维度、遗漏和建议。失败的评分可在面试中重试，完成后才计入对比。
5. 「已掌握」由你手动标记，分数不会自动改变状态。移出复习需要确认，不会删除面试历史；删除原面试、题库或简历也不会影响已有复习快照。

复习内容随备份迁移。同 ID 内容有分歧时保留双方，重复导入同一快照去重；删除不会改写旧备份，导入旧备份会恢复其中的记录。本版支持单题重练，暂不包含自动复习日程或跨题掌握度推断。

## 数据与备份

界面的「备份与迁移」显示实际资料目录，默认为 Electron 用户数据目录下的 `library`。

```text
library.sqlite                  来源、文章、版本、任务、问答记录与索引
model-settings.json             本机模型配置与加密密钥，不导出
retrieval-settings.json         向量及精排配置与加密密钥，不导出
articles/<id>/current.md         当前 Markdown
articles/<id>/versions/<id>.md   不可变历史正文
assets/<hash>.<ext>              本地图片
```

不要直接编辑采集原文。历史版本是恢复依据，启动时只恢复缺失、变化或未完成的 `current.md`，并复用已有索引。v0.5.2 首次升级会整理一次维护记录；本地数据库升级后请使用 v0.9.0 或更新版本打开。图片使用相对路径，文章可脱离应用阅读。

备份包包含来源信息、文章、图片、历史版本及问答记录、面试资料、题库、场次快照及复习记录；不包含网站登录信息、模型设置与密钥、向量缓存或任务队列。问答按 ID 去重，冲突保留双方；重复导入幂等。文章优先采用采集时间更新的版本，时间相同的冲突保留本机当前版本及双方历史。导入不自动采集网站；若本机已开启自动向量索引，则会为导入资料调用配置的 Embedding 服务。

备份限制：100000 个条目、单条目 256 MiB、解压总量 20 GiB。超限或校验失败会拒绝导入。当前格式版本为 7，兼容导入 v1/v2/v3/v4/v5/v6；旧应用不能读取新版备份。

## 验证和打包

```bash
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run dist:mac
npm run dist:win
```

桌面集成测试需要图形环境。单元测试无需访问外网，但协议测试需要监听本机 HTTP 端口。真实网站验收独立运行：

```bash
npm run build
npx playwright test --config=playwright.live.config.ts
```

打包输出在 `release/`。本地测试包尚无商业签名或 macOS 公证；Windows 可打包不等于已在 Windows 上通过运行验收。具体平台验证状态见 [验收记录](docs/verification/release-checklist.md)。

## 已知边界

- 全站发现以站内可发现链接为范围，不保证找到没有链接入口的孤立文章。
- 同源范围不自动扩展到其他子域名；跨域跳转会暂停并提示检查登录/来源地址。
- 未针对每个网站的付费遮罩或特殊验证码适配；发现正文不代表已验证网站所有页面。
- 资料库正文搜索支持中文与代码符号；知识库问答另支持语义检索。
- 问答支持关键词与向量混合召回、可选精排；未配置向量服务时使用关键词。服务失败会显示降级原因。
- 向量使用 SQLite 存储与余弦精确检索，没有 ANN 索引；超大资料库尚未性能验收。
- 每个问题独立检索，不隐式携带其他问题的上下文；最多同时生成两个回答。
- 面试评分是模型练习反馈，不代表招聘结果；当前不包含语音或 OCR。

## v0.9.1 云同步漏传修复

- 同步记录绑定云端地址和同步密钥摘要。更换目标或密钥会重新上传图片与向量；原始密钥不写入同步进度文件。
- 升级后旧版同步完成记录不再复用，首次同步可能重新上传已有图片和向量，以补齐此前可能漏传的数据。
- 只有当前 Embedding 模型下、输入内容匹配的完整向量集合才会上传并标记完成。尚未建立或只建立了部分索引时，界面显示待补传文章数；完成本地索引后再次点击同步。
- 更换模型或重建出不同向量时会重传。远端分块替换前使旧完成标记失效，中断后下次同步可重试。

验收：[v0.9.1 云同步修复](docs/verification/sync-v0.9.1.md)。
