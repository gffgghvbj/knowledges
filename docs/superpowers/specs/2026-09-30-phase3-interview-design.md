# 第三阶段：题库与文字模拟面试

状态：用户已审阅认可，进入实施计划。继承已确认的三阶段需求，不重复确认原有功能范围。

## 目标与现有基础

在拾知 v0.4 的本地资料库、混合检索、问答及备份上，增加题目管理、简历与 JD 管理、逐题文字面试及复盘。继续支持 macOS 和 Windows、DeepSeek / 兼容在线接口与 Ollama；检索沿用当前 Embedding 和 Rerank 设置。此次不包含语音面试。

## 用户流程

1. 在「面试资料」粘贴或导入简历、JD，检查并修正提取文本后保存；可保存多份并按名称选择。
2. 在「题库」手工录入题目与参考答案，或从选定的本地文章整理生成候选题。生成候选题必须经过用户选取后入库。每题保存知识点、难度、类型、参考答案和来源文章版本；标明手工录入、AI 整理或 AI 延伸，不把生成内容声称为原文。
3. 创建面试：选择专题练习或岗位综合、题库随机或 AI 延伸、练习或正式模拟、难度及总题量。岗位综合需选择简历和 JD；专题练习不强制提供。
4. 一次展示一道题，作答后保存。练习模式立即展示评分与解析，再进入下一题；正式模拟结束后统一展示。
5. 面试结束查看逐题反馈、整体得分、薄弱点和关联复习资料，可查看历史、删除场次，并通过备份迁移。

## 文档导入边界（本次建议）

- 简历与 JD 支持粘贴文字、文本型 PDF 和 Word `.docx`，在本机提取，不为提取调用在线模型。
- 暂不支持旧 `.doc`、扫描 PDF 的 OCR、密码保护文档；明确提示转换格式或粘贴文字，绝不保存空白提取结果。
- 提取后提供可编辑预览，只有用户保存后的文本才能用于面试。设置文件大小及文本长度上限，防止超大文件阻塞应用；建议 10 MiB / 每份 30000 字符，超限提示用户精简。
- 保存确认后的文本、名称、类型和时间；不保存或导出原始简历文件。
- 在线面试会发送选定简历/JD、回答和相关资料片段，开始页说明发送范围。密钥仍不进入备份。

## 出题与状态管理

- 题库模式按专题、知识点、难度筛选，单场无重复随机抽取。岗位模式可利用简历/JD选择与排序已有候选题，但不得偷偷补入生成题。可用题不足时提示调整数量或范围。
- AI 延伸模式根据专题或简历/JD及检索结果出题，并可基于实际回答追问。追问占用总题量；默认 5 题，可选 1–20 题。每场保存实际题目与来源，不重新生成已展示题。
- 技术问题使用知识库检索的版本化证据；资料不足时标识参考答案包含模型补充，不伪造来源。项目题针对简历中的职责、决策和效果，不把模型猜测写成用户经历。
- 状态区分准备中、等待作答、处理回答、等待继续、完成、失败和中止。回答在模型请求之前落库；重复提交或重试不会新增同一题的回答或重复推进进度。
- 切换页面不丢失已提交回答，未提交的草稿也保存；重启保留场次进度。被中断的网络步骤标记可重试，不自动重复调用收费接口。
- 每场固定简历/JD文本、配置、模型名称和规则版本快照。后续修改资料不会改变历史依据。模型配置改变后重试需显示实际使用模型。
- 正式模拟的参考答案与评分由主进程保留，结束前提供给页面的数据中不包含这些字段。

## 评分与报告

- 量表版本 `interview-v1`，总分 100。技术题：正确性 50、完整性 30、表达清晰度 20；项目题：职责说明 25、技术取舍 30、解决过程 30、回答一致性 15。
- 模型返回各维度得分、对应回答的理由、遗漏与错误、改进建议及参考答案；程序校验结构和分数范围，并按固定权重计算总分，不直接采信模型随意给出的总分。
- 项目评分评价回答内容，不验证履历真实性；证据不足时明确说明，不能把没有出现在知识库中的个人经历判断为错误。
- 总报告使用已完成评分汇总，展示实际已答/计划题数、逐题得分、薄弱点和引用资料。缺少评分不能当作 0 分悄悄计入平均分；失败需重试或明确以部分结果结束。
- 评分只是练习反馈，不保证等同招聘评价；历史记录保留规则、模型及时间，允许追溯。

## 数据、备份与实现边界

- 在现有 SQLite 增加面试资料、题库和场次记录；沿用受限 IPC 与本机文件选择，不开放任意文件路径读取。
- 引用关联实际文章及历史版本，题目和场次保留必要快照。删除题库条目或简历不破坏历史面试。
- 备份新增上述业务数据，继续接受旧格式。稳定 ID 去重、同 ID 内容冲突保留双方、重复导入幂等；导入前校验记录关系与引用，不恢复网络任务。原文档、密钥和派生向量不导出。
- 独立的面试服务管理状态机，复用模型传输与混合检索；页面分为题库、面试资料、创建/进行面试、复盘历史，避免把全部逻辑放入现有问答页面。

## 验收

- PDF、DOCX 与粘贴三种入口均可确认并使用；空文档、扫描 PDF、非法或超限文件显示可操作错误。
- 专题/岗位、题库/AI、练习/正式组合均可完成。岗位题能体现实际简历和 JD；题库不足无隐式补题；追问严格计入题量。
- 失败、取消、重复点击、重启及删除不会重复推进场次、丢失已提交回答或复活删除记录。
- 正式模拟结束前 IPC 返回值也不泄露解析和分数；评分范围与引用严格校验。
- 历史依据不随原资料更新改变，备份往返和冲突合并通过回归；继续执行现有采集、问答、分类与向量检索测试。
- 交付 macOS 应用与 Windows 便携包。无 Windows 实机或真实模型凭据时明确区分打包/协议测试和实机/模型质量验收。
