# v0.7.0 网页提取规则验收

日期：2026-10-01。

## 实现范围

- 网站添加时选择自动匹配、通用、小林 coding、JavaGuide、代码随想录规则。已有来源可在「提取规则」中修改。
- 规则定义正文、标题、扫描链接 CSS 选择器，排除元素与发现链接的路径前缀。支持代码语言/缩进处理及折叠摘要格式化。
- 自定义规则使用严格校验的 v1 JSON，支持导入、编辑、导出；无脚本执行能力。示例见 `docs/rules/programmercarl.json`。
- 单篇预览展示阅读效果与 Markdown，复用来源登录会话，不写入文章、不下载图片。地址必须在来源允许范围内；预览最多 200000 字符，JSON 最多 32000 字节。
- 保存不自动重采集；需手动更新。进行中的任务禁止改规则，暂停后仍有请求处理时也须等其结束。文章版本、问答引用及复习记录继续保留。
- 路径前缀约束发现链接；网站入口仍作为扫描种子读取，已有文章更新不被排除。自定义选择器不匹配正文时明确报错，不偷偷回退到整页。

## 用户样例验证

网页：<https://programmercarl.com/hot100/0001.two-sum.html>。

读取公开 HTML 后，对照原有提取器与新规则：

- 原代码块语言信息位于外层 `pre` / `div`，而行号位于 `.line-numbers-wrapper`。
- 原提取结果为 4189 字符，5 个代码块均无语言信息。
- 新规则结果为 3644 字符，5 个语言标记分别为 `cpp`、`python`、`java`、`go`、`javascript`。
- 用 Markdown 解析器取出代码块，与网页 DOM 中 5 个 `pre code` 的文本逐块精确比较，全部一致；独立行号不再进入 Markdown。
- 实际网页正文仅用于本机临时验证，仓库回归测试使用相同 HTML 结构的自建简短代码样例。

## 兼容与交付

- SQLite schema 8；旧应用会拒绝打开新版数据库。规则作为来源属性保存，不重建文章索引。
- 备份 v6，兼容导入 v1–v5；新来源连同规则一起导入，已有同源网站保留本机规则。需要替换时单独导入 JSON 并保存。
- macOS：`release/v0.7.0/mac-arm64/拾知.app`；Windows：`release/v0.7.0/Shizhi-Windows-x64-0.7.0.zip`。
- macOS 未发行签名/公证，Windows 未实机运行。没有使用用户 API Key 或修改用户实际资料库。
- 暂不支持可执行脚本插件、公式排版、可视化元素选择或针对动态网页的自定义等待/点击动作。本轮不宣称已验证代码随想录全站页面。
