# v0.9.0 逐篇采集与质量检查

验收日期：2026-10-02。独立临时资料库、本地 HTTP 网页夹具；不访问用户资料库或模型密钥。

## 已实现

- 扫描结果支持标题/栏目/URL 搜索、栏目筛选、逐篇勾选、选择本页、清空选择及路径前缀排除。每页 50 条，选择跨筛选与分页保留；排除项不会提交。
- 逐篇采集将网站更新范围设为本次所选 URL，之后更新直接处理这些链接。按栏目采集清除逐篇限制；单篇采集不修改网站更新范围。
- 网站、任务文章和资料库文章均有单篇预览/采集入口，可临时选择规则。提取规则随任务固定，暂停后恢复不会混用后来的网站规则。
- 质量检查包括正文过短、登录/解锁提示、空代码块、链接密集、图片地址缺失/下载失败。任务可筛选待检查项，文章版本保存检查结果。网页原始正文中的空代码块在 Markdown 转换之前检查，避免转换时丢失异常信号。
- 检查为提示，不能保证内容正确或完整。预览不下载图片。真正需要登录的页面仍暂停等待手动登录。
- 回收站文章跳过；重采不会恢复已删除文章。已有内容改变时保存新版本，未改变的正文复用原版本。
- 备份格式 v8，读取 v1–v8；数据库版本 10。逐篇范围和版本质量随备份迁移。导入已有网站保留本机范围和规则。导入的更新 URL 必须为规范的同源地址，不接受外站地址。
- 搜索延迟计算、列表分页；历史任务的文章明细首次展开才渲染。
