# v0.5.2 启动优化验收

日期：2026-10-01。

## 原因和改动

旧版在创建窗口之前打开资料库，无条件重写每篇文章的 `current.md`，清空全文搜索索引并重新处理所有知识片段。新版本先显示启动页，再分批检查资料，每 20 篇让出主进程以处理进度和关闭事件。业务 IPC 等待初始化完成，防止用户操作尚未准备好的库；失败显示明确原因。

新增本地维护记录保存文章的已索引版本、标题、索引算法版本、片段数量，以及已生成 Markdown 的版本、修改时间和大小。正常重启只检查这些记录和文件状态，不重新读取/写入全部正文。文章变化、索引缺项、文件缺失或文件状态改变时只修复相应文章。采集、恢复历史版本和备份导入会更新这些记录；备份重复导入不再重建所有文章索引。

任务恢复只读取处理中采集任务、未完成问答及未完成面试，不再在启动时解析全部历史答案和简历快照。本地图片协议在页面加载之前注册，确保提前显示窗口不影响文章图片。

## 验证

- 类型检查通过；25 个测试文件、77 项单元测试通过。
- 新测试验证正常重启不调用文章生成/索引写入、旧库升级、中断后只处理剩余文章、正文写入中断恢复、索引缺项自动修复、正常搜索及历史保留。
- 200 篇合成文章，每篇 4588 字符：同一次对比中，强制全量维护（模拟旧流程）为 277ms，增量重开资料库为 11ms。强制路径包含新版本维护记录的写入，并非旧安装包的端到端对照。该样本为本机测试，**不包含 Electron 启动、首屏和系统安全检查时间**，也不是所有资料规模的速度保证。
- 开发版及最终 macOS ARM64 包各 11 项桌面回归通过，包含原有采集、图片阅读、登录、问答、面试、中文输入和草稿保存；新增未来数据库版本的启动失败页面和业务调用保护测试。

## 升级和边界

数据库升级至 schema 6，首次从旧版启动会进行一次整理，之后复用维护记录；无需重新采集文章或手动重建向量。整理中退出后，下次会继续未完成的部分。维护记录不进入备份，备份格式仍为 v4。

**升级后的本地数据库需使用 v0.5.2 或更新版本，旧应用无法直接打开。** Markdown 原文、历史版本、问答和面试记录保留。不要同时运行多个版本操作同一个资料库。

当前 Markdown 副本依靠版本、修改时间和大小检查，不提供针对外部恶意篡改的完整性审计；不可变历史正文仍是恢复依据。运行速度也受 Electron、系统磁盘及 macOS 未签名应用检查影响。

交付目录：`release/v0.5.2`。macOS ARM64 为未签名/未公证本地包；Windows x64 仍需实机验收。

两端安装包 asar 版本均为 0.5.2，文档 worker、中文 CMap 与平台原生依赖已核对；Windows ZIP 全条目校验通过并生成 SHA-256。未做 Windows 实机运行验收。
