# v0.6.0 针对性复习验收

日期：2026-10-01。

## 交付范围

- 已完成或提前结束的面试报告可逐题加入复习；同场同题重复加入幂等，正式面试未结束时禁止通过接口加入。
- 复习列表支持题目/知识点搜索、知识点筛选、待复习/已掌握筛选、50 条分页；列表只传摘要，按选择加载回答详情。
- 单题重练使用原题、引用和当时简历/JD 快照，可选择在线模型或 Ollama，沿用原有草稿、失败重试和评分流程。
- 已完成的重练保留回答和评分快照，与最初回答并列展示；可选择任意一次已评分练习。掌握状态仅由用户手动修改。
- 移出复习需确认，不删除面试历史；删除源面试、题库或资料不会删除复习快照。删除复习后，正在完成的评分不会恢复被删记录。
- 评分结果和复习对比通过同一 SQLite 事务保存；重试不会重复记录同场作答。

## 数据兼容

SQLite schema 从 6 升至 7，仅新增 `interview_reviews` 表。升级后的数据库必须由 v0.6.0 或更新版本打开；不自动重建文章索引。

备份格式为 v5，仍可读取 v1–v4。新增复习内容包括原回答、题目引用、简历/JD 快照及历次已评分回答。校验评分量表、引用原文和题目一致性；同 ID 分歧保留双方，导入重练场次会映射到对应复习记录。重复导入相同快照幂等。旧备份中的已删记录会重新导入。

## 验证结果

- `npm run typecheck` 通过。
- `npm test`：26 文件、80 项通过。包含新增快照独立性、重复加入、失败重试、删除后迟到结果、正式模式隔离及备份分歧合并测试。
- 开发版桌面测试：原有 10 项通过；新增完整复习流程最初因筛选框无障碍名称不明确而超时，补充明确名称后针对该流程重跑通过（6.4 秒）。
- 最终 macOS ARM64 成品：完整 11 项 Playwright 测试通过（27.4 秒），包含报告加入复习、筛选、重练、回答对比、标记掌握和确认移出。
- 人工查看测试截图，复习列表、操作区及并列回答未见遮挡或溢出。
- macOS 与 Windows 包均核对版本 0.6.0、复习业务代码、PDF worker/CMap 和各平台 native canvas 依赖。

测试使用临时资料目录和本机 HTTP 模型夹具，没有访问用户真实资料、API Key 或付费模型。测试分数仅用于验证流程，不能证明真实模型评分质量。
