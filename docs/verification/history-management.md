# 提问记录管理 · v0.4.0

用户确认的范围：单条与批量删除，删除前确认；手动自定义分类，每条记录一个分类；新建、重命名、删除分类与筛选、批量移动；分类删除后记录回到未分类；分类随备份合并。

## 行为

- 原有记录与新提问默认未分类。分类名去除首尾空白、最多 60 字，空名称、重复名称和保留名称「全部记录」「未分类」被拒绝。
- 左侧可按分类筛选，勾选记录后移动到分类；全选作用于当前筛选结果。单条与批量删除共用确认弹窗，取消不修改数据。
- 删除问题不影响资料原文。生成中的记录被删除时中止请求，后续写入只能更新仍存在的记录，不会重新插入；生成完成时保留数据库中的最新分类。
- 分类重命名批量更新归属；删除分类将归属清空，保留问题与答案。错误直接显示在操作弹窗中。
- SQLite 从 v3 升到 v4，新分类表保存空分类。备份升到 v3，接受旧 v1/v2；同名分类合并，问答 ID 冲突继续保留双方，重复导入幂等。
- 本机删除不会修改已有备份。导入旧备份会重新导入其中已删除的记录，不包含跨设备删除同步。旧版本应用拒绝打开新版数据库与备份。
