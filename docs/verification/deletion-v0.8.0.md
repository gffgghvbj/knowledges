# v0.8.0 删除与回收站验收

日期：2026-10-01。

## 用户确认范围

补齐网站来源、资料库文章、采集任务三类删除入口。删除网站默认保留已采集文章，删除文章支持恢复。

## 最终行为

- 来源卡片可删除，确认后隐藏来源并删除该站采集任务，保留文章、引用和来源配置。重新添加同一来源恢复配置；网站登录会话不会被清除。
- 资料库支持单篇删除、勾选本页批量删除，删除前确认。文章进入回收站，退出正文搜索、关键词检索及向量索引。已有引用通过历史版本仍可阅读。
- 回收站可查看文章及版本，按标题/栏目筛选，并逐篇或勾选本页恢复。网页重新采集和启动维护不会自动恢复回收站文章。
- 采集任务支持单条删除和清理已完成记录，保留已采集文章。任务列表每页最多 50 条。
- 删除期间已经发出的网页/图片请求可以返回，但返回结果不会重新创建任务或保存文章；后续图片请求也停止发出。网络请求本身不保证立即中断。
- 文章回收站保留 Markdown、图片和历史版本，不释放这些磁盘占用；本版没有永久删除/清空回收站。

## 数据兼容与恢复

- SQLite schema 9，用于保护新增删除状态语义；v0.7.0 及更早应用不能打开升级后的数据库。
- 备份 v7，兼容导入 v1–v6。导出包含回收站文章、所有历史版本及已移除来源的配置，确保问答和面试引用不丢失。
- 导入新库时保留来源和文章的删除状态。已有库合并时，正文版本仍按时间处理，但删除/恢复状态以本机为准，旧备份不覆盖本机决定。
- 恢复文章会重建关键词索引；启用中的向量服务可按现有配置重新生成缓存。
