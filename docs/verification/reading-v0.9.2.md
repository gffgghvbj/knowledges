# v0.9.2 全屏阅读

日期：2026-10-16。

资料库文章新增「全屏阅读」按钮。模式内隐藏应用侧栏、顶栏、文章列表、版本及管理操作，只显示文章和固定的标题/退出栏。复用当前 Reader 与 DOM，不重复读取或转换 Markdown。Esc 和退出按钮均可返回；切换时保留滚动偏移，退出后焦点回到入口。键盘 Tab 限定在阅读区可见控件与链接内。该模式占满应用窗口，不切换操作系统全屏；可配合系统最大化使用。

验证使用隔离临时资料库，不读取或修改用户笔记。

- 新增桌面用例先在旧版失败（缺少全屏入口），实现后通过。
- 专项用例检查侧栏/列表/删除入口隐藏，代码保留，进入及退出滚动偏移、Esc/按钮退出与焦点恢复。
- 类型检查通过；完整单元回归 30 文件 / 105 项通过。
- macOS 打包版原有 15 项桌面回归通过；全屏阅读用例在增加等待正文加载后重跑通过（1.4 秒）。首次新断言失败是测试提前滚动空阅读区，并非进入模式时丢失位置。共 16 项桌面用例验证通过。

产物：release/v0.9.2。macOS ARM64 未发行签名/公证；Windows x64 未在 Windows 实机运行。未改变数据库或备份格式。
