# 第二阶段验收记录

日期：2026-09-30。版本：0.2.0。

## 功能

- DeepSeek 默认在线配置、可编辑的兼容 API 基础地址及模型名；Ollama 本地接口。
- 主进程调用模型；safeStorage 加密 API Key；密钥不回传界面、不进入备份；更换地址清除旧密钥。
- 全部/网站/栏目/主题范围检索；当前版本段落索引；答案段落关联不可变版本、行号及原文摘录。
- 资料不足显式提示，模型补充分开呈现；无效结构或不存在的引用拒绝采纳。
- 先保存问题再发请求；取消、120 秒超时、网络错误、重启中断可重试；旧问题不覆盖。
- v2 备份包含问答；兼容导入 v1；冲突保留双方，重复导入幂等；导入校验引用摘录与历史原文。

## 验证

- TypeScript 类型检查通过。
- 34 项单元测试通过（12 个测试文件）：保留第一阶段 25 项测试，新增检索范围/版本、HTTP 协议、取消/超时/恢复、密钥边界、问答合并、v1 兼容、伪造摘录拒绝、超长段落与旧数据库升级。
- 开发版 Electron 桌面测试 4 项通过：原有 3 项流程，加上模型配置→问答→引用→重启持久化→无资料不足提示。
- 问答界面截图已人工查看，无遮挡或横向溢出。
- macOS arm64 v0.2.0 打包成功；直接运行打包产物完成全部 4 项桌面测试。问答测试额外切换文章当前版本，确认历史引用仍打开原版本文件。
- Windows x64 v0.2.0 打包成功，ZIP 完整性通过；产物在 `release/v0.2.0/`，SHA-256 另存于同目录。

## 独立审查与修复

- 独立只读审查完成，无 Critical 问题，两项 Important 问题已修复。
- 超长段落导致问答备份不能重新导入：回归测试先失败于 12000 字符限制，再统一证据与上下文上限后通过。超预算段落不再消耗其他段落的预算。
- 历史引用中的「打开 Markdown」错误打开当前版本：桌面回归先复现 `current.md` 与历史路径不符，再通过版本 ID 校验和不可变文件路径修复，打包版测试通过。
- 另补旧版 SQLite 升级专项验证：重建第一版实际表结构，打开新版自动建立段落索引，原文和版本 ID 不变。
- 没有遗留代码审查问题；以下真实环境验证仍有边界。

## 实施决定

- 用户已确认整体设计并授权开始第二阶段，因此沿用审批与当前功能分支，连续实现，无重复确认。
- 采用本地中文分词、关键词段落排序，无需额外 embedding 服务。代价是完全改写、同义表达的召回能力弱于语义检索；界面允许关键词和范围控制，后续可替换索引实现。
- 采用完整 JSON 响应而非流式渲染，便于在展示前验证引用。等待过程中显示生成状态并允许取消。
